#  Conversor de Monedas

Bienvenido al **Conversor de Monedas** desarrollado en Java.  
Este proyecto permite realizar conversiones rápidas entre distintas monedas latinoamericanas y el dólar estadounidense.

---

##  Funcionalidades

El programa ofrece el siguiente menú interactivo:

   Sea Bienvenido al Conversor de Monedas
    1) Dólar --> Peso Argentino
    2) Peso Argentino --> Dólar
    3) Dólar --> Real Brasileño
    4) Real Brasileño --> Dólar
    5) Dólar --> Peso Colombiano
    6) Peso Colombiano --> Dólar
    7) Salir
    Elija la opción válida:
---

## 🛠️ Tecnologías utilizadas
- **Java** (versión 8 o superior)
- **Gson** para parsear respuestas JSON de la API
- **ExchangeRate-API** para obtener tasas de conversión en tiempo real
